CAL HACKS 12.0
Winner Regeneron: Honorable Mention | AI voice triage | real-time scheduling and symptom matching

Cura is an AI-powered medical voice assistant designed to make healthcare more accessible and responsive. It listens to patient symptoms, offers personalized guidance, connects users to doctors, and helps schedule appointments through natural conversation.

We built Cura to support both patients and healthcare professionals by automating symptom triage, appointment scheduling, and follow-up care inside one cohesive workflow.

The project combines real-time voice AI, generative language models, and healthcare data systems while keeping responses cautious, helpful, and privacy-aware.

  • Built LiveKit Agents for real-time voice calls, STT/TTS, and natural back-and-forth dialogue.
  • Integrated FastAPI and MongoDB for patient data, healthcare logic, and dashboard workflows.
  • Used Chroma for symptom similarity search and CreaoAI for scheduling, calendar, and cross-platform UI flow.

PROJECT 02

THREATGRID

6 threat types, 4 severity levels, and a 3-step neutralization flow on a live globe concept

THREATGRID is a cybersecurity intelligence dashboard concept built around a dark rotating 3D globe where threat events pulse at their geographic origin.

Clicking a threat opens an AI analyst panel that explains the attack vector, affected systems, and a step-by-step neutralization guide in a workflow that feels like a real ops dashboard.

The idea is educational first, but it is framed like a serious security tool so students and professionals can understand what is happening and how to respond.

  • Interactive globe with simulated threat nodes spawning at geographic coordinates.
  • AI analyst panel types out a breakdown and mitigation sequence for each threat.
  • Neutralization flow clears the threat and produces a debrief-style report.

PROJECT 03

GPU-Accelerated Pokémon Card Classifier

199.871 s → 66.714 s after GPU and DataLoader throughput tuning

I built this classifier as an end-to-end machine learning pipeline for Pokémon card images, with the goal of making the data path and training behavior easier to improve rather than just easier to run.

The project uses PyTorch, Torchvision, and CUDA so the GPU does the heavy lifting while the CPU stays focused on orchestration, preprocessing, and input pipeline work.

I also used profiling tools to reduce data-loading overhead and keep the training loop centered on throughput instead of hidden stalls.

  • Collected card images asynchronously and organized them into training, validation, and test splits.
  • Normalized noisy labels to keep the supervised dataset consistent.
  • Tuned the input pipeline and GPU execution path to improve throughput instead of just raw model code.
